# DSAbyHimanshu — Daily DSA Animations ⚡

> **Interactive side-by-side Brute Force vs Optimal visualizer with cosmic noir aesthetic.**  
> Solved: LC-1 (Two Sum), LC-49 (Group Anagrams), LC-128 (Longest Consecutive Sequence), LC-217 (Contains Duplicate), LC-238 (Product of Array Except Self), LC-242 (Valid Anagram).

---

## 🌟 Features

- **Side-by-Side Dual Visualizer**: Live step-by-step side-by-side comparison between **Brute Force** and **Optimal** algorithmic approaches.
- **Cosmic Noir 4K Background**: Cinematic 4K/1080p ambient background with particle sparks.
- **Apex Legends Tactical UI**: Rajdhani & JetBrains Mono typography, frosted glassmorphism cards, and interactive neon badges.
- **Infographic Cheat-Sheet Mode**: Comprehensive visual cheatsheet for key DSA patterns (Two Pointers, Hash Map / Frequency, Prefix/Suffix Products, Sliding Window).
- **Official LeetCode Integration**: Quick jump links to solve each problem directly on official LeetCode.
- **Zero-Dependency Core**: Pure HTML5, modern CSS3, and Vanilla JavaScript with hardware-accelerated animations.

---

## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/himxnshu/DSA-Animation.git
   cd DSA-Animation
   ```

2. Open with any static file server (e.g. VS Code Live Server or Python):
   ```bash
   python -m http.server 5500
   ```

3. Navigate to `http://localhost:5500` in your browser.
